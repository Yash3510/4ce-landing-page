# 4CE Landing Page

Interactive 3D workstation landing page built with Next.js 16, React Three Fiber, Three.js, WebGPU shaders, and Tailwind CSS.

## Features

- **Interactive 3D Workstation**: Real-time 3D models with interactive lighting, reflections, and camera splines.
- **CRT Post-Processing Pass**: Phosphor scanlines, chromatic aberration, barrel distortion, and CRT noise.
- **Smooth Inertial Scrolling**: Lenis smooth scroll engine synchronizing page progress with Three.js camera transforms.
- **Clean Architecture**: Next.js App Router, TypeScript strict mode, and Tailwind CSS.

## Tech Stack

- **Framework**: Next.js 16 (App Router, React 19, TypeScript strict)
- **3D & Graphics**: Three.js, React Three Fiber (`@react-three/fiber`), Drei (`@react-three/drei`)
- **Motion & Scrolling**: Lenis Smooth Scroll
- **Styling**: Tailwind CSS v4

## Getting Started

```bash
# Install dependencies
npm install

# Run the development server
npm run dev

# Run production build
npm run build
npm run start
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
